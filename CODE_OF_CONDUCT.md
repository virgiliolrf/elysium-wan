# Code of conduct

Elysium follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:
- be respectful;
- assume good faith;
- keep discussions about the work.

Harassment and personal attacks are not tolerated, in issues, pull requests or anywhere else the project lives.

To report unacceptable behavior, contact the maintainer privately through GitHub ([@virgiliolrf](https://github.com/virgiliolrf)).
Reports are handled confidentially.
